# 개인정보 및 문서 처리 안내

현재 MVP는 사용자가 선택한 HWP/HWPX 파일을 브라우저 내부에서 읽고 렌더링합니다.
프로젝트 자체에는 문서를 서버로 업로드하는 API, 데이터베이스 저장 기능, 회원가입 기능이 없습니다.

따라서 현재 소스 그대로 배포하는 경우 문서 파일은 서비스 운영 서버에 저장되지 않습니다.
단, 향후 서버 변환, 분석 로그, 오류 수집, 클라우드 저장 등의 기능을 추가하면 이 안내는 실제 동작에 맞게 반드시 수정해야 합니다.

공개 서비스로 운영할 경우에는 호스팅 사업자, 분석 도구, CDN 등 제3자 서비스가 수집하는 접속 로그나 쿠키가 있는지도 별도로 확인하세요.
