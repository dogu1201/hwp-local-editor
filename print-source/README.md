# HWP 바로인쇄 MVP v3

브라우저에서 HWP/HWPX 파일을 열어 미리보고, 여러 문서 중 원하는 문서만 선택해 한 번에 인쇄하기 위한 실험용 MVP입니다.

## v3 주요 기능

- HWP/HWPX 여러 파일 동시 선택 또는 드래그앤드롭
- 추가 파일을 나중에 계속 목록에 추가
- 문서별 인쇄 체크박스
- 전체 선택 / 전체 해제
- 개별 제거 / 선택 문서 일괄 제거 / 전체 제거
- 체크된 문서 수와 예상 페이지 수 표시
- 체크된 문서만 현재 목록 순서대로 한 번의 브라우저 인쇄 작업으로 출력
- 인쇄에서 사이트 UI, 라이선스 고지, 미리보기 배지를 자동 제외
- 문서를 서버로 업로드하지 않고 브라우저 메모리에서 처리

> 참고: 페이지를 새로고침하거나 브라우저를 닫으면 선택한 로컬 파일 목록은 사라집니다. 브라우저 보안상 사용자의 로컬 파일을 허가 없이 다시 불러올 수 없기 때문입니다.

## 실행 방법 (Windows PowerShell)

PowerShell 실행 정책 때문에 `npm`이 차단되는 PC에서는 아래처럼 `npm.cmd`를 사용하세요.

```powershell
npm.cmd install
npm.cmd run dev
```

터미널에 표시되는 주소(보통 `http://localhost:5173/`)를 Chrome 또는 Edge에서 엽니다.

## 빌드

```powershell
npm.cmd run build
```

`dist` 폴더가 생성됩니다.

## 렌더링 관련 주의

이 프로젝트는 `@rhwp/core`를 사용합니다. 원본 문서에서 사용한 글꼴이 PC에 없거나, 라이브러리가 특정 HWP 기능을 완전히 지원하지 않는 경우 줄바꿈, 표 크기, 페이지 나눔 등이 한컴오피스와 달라질 수 있습니다. 인쇄 전에 반드시 미리보기를 확인하세요.

## 개인정보

현재 버전에는 문서 업로드 API나 데이터베이스가 없습니다. 사용자가 선택한 문서는 브라우저 메모리 안에서 처리됩니다. 자세한 내용은 `PRIVACY.md`를 참고하세요.
