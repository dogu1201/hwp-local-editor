# HWP Local Editor

한컴 한글 설치 없이 Windows 브라우저에서 HWP/HWPX 문서를 열고 직접 수정한 뒤 HWP로 저장하는 로컬 편집기입니다. [RHWP](https://github.com/edwardkim/rhwp) 오픈소스 편집 엔진을 포함합니다.

## 실행

1. 저장소를 ZIP으로 내려받아 압축을 풉니다.
2. `HWP-Local.exe`를 실행합니다.
3. 브라우저에서 **파일 열기**를 눌러 문서를 선택합니다.
4. 문서를 수정하고 **수정본 HWP 저장**을 누릅니다.
5. 편집기 탭을 닫으면 백그라운드 실행기가 약 20초 안에 자동 종료됩니다.

별도의 한컴 한글, Python, Node.js 설치가 필요하지 않습니다. `sdk` 폴더는 실행 파일과 함께 두어야 합니다. GitHub 배포본은 RHWP 공식 웹 편집기를 불러오므로 인터넷 연결이 필요합니다.

상세 사용법과 검증 결과는 [사용방법.md](사용방법.md)와 [검증결과.json](검증결과.json)을 참고하세요.

## 검증

사용자가 제공한 HWP 2개를 대상으로 열기, 렌더링, 텍스트 수정, HWP 내보내기, 재열기를 검사했습니다. 수정 직후와 재열기 후 텍스트 및 쪽 수가 유지됐습니다. 원본 문서는 저장소에 포함하지 않습니다.
